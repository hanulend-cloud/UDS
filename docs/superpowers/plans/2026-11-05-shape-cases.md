# 형상 후보 표 구현 계획

**목표:** 형상 최적화의 후보 전부를 표로 남겨, 나중에 골라 3D로 보고, 정식 계산 후 적용할 수 있게 한다.
**결정(사용자 승인):** 마지막 실행 1회분만 보관. 스윙 뒤 이어서 한 정밀 탐색은 한 표로 합침. 형상만 대상.

**구조**
- `src/ui/m3/shape-cases.js`(신규, 순수 함수): 행 합치기, 정렬, 조건 지문, 표 HTML.
- `src/engine/mech3d/autodesign.js`: `cfg.fixedShape` = 고른 후보를 그대로 판정(현재안 유지 판단을 건너뜀).
- `src/ui/m3/app.js`: 후보 기록, 저장(`mspec.shapeCases`, 태그 meta), 미리보기, 계산 실행.
- `src/ui/m3/autodesign-panel.js`, `styles.css`: 표 표시.

**작업(각각 시험 먼저)**
1. shape-cases.js: 같은 후보는 광선이 많은 값으로 합침, 정식 값 유지, 탈락 후보 맨 아래, 지문은 형상·이름·목표 변경에 영향 없음.
2. 엔진: fixedShape 면 더 나쁜 후보도 결과로 나옴, 변경 없음 후보도 명시 형상으로 유지.
3. 패널: 표 표시, 정렬 단추, 선택 행 버튼, 조건 변경 경고.
4. app.js: 기록·합치기·미리보기·계산·적용·되돌리기 기록에서 제외.
5. 화면 확인: 실제 실행, 새로고침 유지, 조건 변경 표시, 후보 적용. 관련 시험 후 커밋·푸시.
