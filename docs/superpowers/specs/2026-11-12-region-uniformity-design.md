# 2D 영역 균일도 · 큰 창 확대 — 설계 (2026-11-12, 사용자 승인)

## 목적
2D 광량 분포에서 원하는 영역 하나를 골라 그 영역의 균일도를 전체 결과와 나란히 비교한다. 큰 창(⤢)에서 확대·이동해 영역을 정확히 고른다.

## 결정 사항(사용자)
- 영역 균일도 = 지금 판정과 같은 식(길이 균일도·폭 균일도) — 전체 결과와 바로 비교.
- 영역은 한 개(새로 그리면 바꿈).
- 파일에는 저장하지 않음(세션 동안만).
- 표시 전용 — 판정 숫자·목표·최적화는 바뀌지 않음.

## 화면
1. 큰 창(2D 광량 분포 ⤢)
   - 휠 = 마우스 위치 중심 확대(1~20배), 끌기 = 이동, 더블클릭 = 전체 보기.
   - [영역 선택] 단추: 켜면 끌기 = 사각형 그리기(칸 경계에 맞춤). ✕ 또는 Esc = 지우기.
2. 사각형 테두리는 큰 창과 작은 2D 카드 둘 다에 그림.
3. 비교 표(큰 창 아래 · 작은 2D 카드 아래, 영역이 있을 때만):

   |      | 전체 | 선택 영역 (L×W mm) |
   |------|------|------|
   | 길이 | 22.4% | 61.3% |
   | 폭   | 17.6% | 55.0% |
   | 평균 | 100% | 112% (전체 평균 대비) |

   값은 fmtJudge(0.1% 내림). 영역 폭이 2칸 미만이면 폭 = '–'.

## 계산
- `regionStats(G, accs, obs, rect)` (순수, tally.js): rect = { s0, s1, w0, w1 } mm → 칸 범위 [i0,i1)×[j0,j1). 잘라 낸 격자 G'(ns', nw', valid·area 부분, closed=false)와 배치별 누적을 잘라 `tallyStats` 그대로 호출 → { Ulen, Uwid, seLen, seWid, relNoise } + 평균 비(영역 평균 / 전체 평균).
- 배치별 누적은 점진 계산 스냅숏(bins)에서 compute() 와 같은 정규화로 얻음.
- 폭 창 길이(winS)는 설정 그대로; 영역이 창보다 짧으면 창 1개.

## 유지
- 영역은 mm 좌표로 기억 — 계산이 진행되면 표가 따라 갱신, 다시 계산해도 유지.
- 관측면(면·방향)이 바뀌면 지움. 저장·불러오기와 무관.

## 시험
- regionStats: 영역 = 전체이면 tallyStats 와 같은 값; 알려진 맵에서 영역 길이·폭 균일도; 폭 2칸 미만 → Uwid null; 평균 비.
- 확대 변환(순수): 화면↔mm 좌표 왕복, 휠 확대가 마우스 지점을 고정, 사각형 칸 맞춤.
- 브라우저: 큰 창에서 확대·이동·영역 그리기 → 표 값이 regionStats 와 같음.
