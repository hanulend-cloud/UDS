# 시뮬레이션 결과판 단순화 — 설계 (2026-11-23)

## 목표
결과판의 글씨를 줄이고, 늘 봐야 하는 값은 상단 띠에 상시 표시하며, 상태 줄 줄바꿈 깜빡임을 없앤다.

## 결정 사항 (사용자 승인)
1. **용어**: 미리보기 → **Quick**(배지 `Quick · 판정 안 함`), 정밀 계산 → **Final**. 버튼 `[정밀 계산]` → `[Final 계산]`, `[미리보기로]` → `[Quick으로]`. 툴팁 설명문도 같은 용어로.
2. **상단 띠(①~⑤ 단계 띠)**: 오른쪽에 4칸 추가 — 길이 균일도 · 폭 균일도 · 평균 광량 · 광효율. 칸 크기(높이·글씨)는 기존 ①~⑤ 칸과 비슷하게. 균일도는 목표 미달이면 빨강, 형식은 fmtJudge(79.9%). 계산 전엔 `—`.
3. **결과판**:
   - 제목 줄: `시뮬레이션` · 모드 배지(Quick/Final) · 판정(✕ 목표 미달 / ✓ 목표 달성) · [기구 최적화로 개선 →].
   - 진행 한 줄: 진행 막대 + `80%` · `오차 ±2.23% → 목표 ±2.00%` · `경과 m:ss` · `남은 시간 약 m:ss`(추정 불가면 생략) · ⓘ(대칭·화질·칸 크기 상세는 툴팁).
   - 균일도·광량·광효율 카드는 결과판에서 제거(상단 띠로 이동). 계산 추이 그래프 2개는 유지.
4. **깜빡임**: 상태/진행 줄은 높이 고정 1줄(`white-space:nowrap; overflow:hidden; text-overflow:ellipsis`), 전체 문구는 title 로.
5. **여백**: 브라우저 상하좌우 끝과의 간격 최소화(약 4px), 패널 사이 간격도 축소.

## 남은 시간 추정
오차는 광선 수의 제곱근에 반비례 → 목표 광선 수 ≈ 현재 광선 수 × (현재 오차/목표 오차)², 남은 시간 = (목표 − 현재) / 최근 광선 속도. 계산 한도(광선 수·시간)가 더 먼저면 그 한도로 계산.

## 회귀 방지
- 기존 결과판 카드에 있던 값(목표·미달 %p 포함)은 상단 띠 칸의 title 에 남긴다.
- 레이아웃 변경 뒤 모든 컨트롤(화질·실제 비율·색상표·회전·⤢·최적화 버튼) 동작 재확인.
- 순수 함수(용어, 남은 시간, 띠 칸 값/색)는 단위 테스트, 화면은 브라우저로 확인.

## 추가 결정 (같은 날, 화면 확인 뒤)
- 계산 추이(오차·균일도) 그래프 일단 숨김 — `app.js` `SHOW_TREND = false`(true 로 되살림).
- 결과판 글 간략화: 상태 `완료`/`계산 중`(전체 글은 툴팁), 모드 줄 `Final · 저화질 1.5 mm · 노이즈 2%`, 단추 `최적화로 개선 →`.
- 상단 ④·⑤ 칩은 숫자·판정 반복 없이 짧게(`목표 미달`, `필요`) — 전체 글은 툴팁. 1280 폭에서 한 줄 유지.
- 결과 요약 영역: 제목 없이 배색 B(네이비 바탕 · 시안 테두리, 광량·효율 = 시안 굵은 글씨, 길이·폭 = 판정 색 칸).
- (2026-11-24) 상단 띠 한 줄 고정: 1260 px 이상은 늘 한 줄(⑤ 상태 글만 말줄임), 미만은 결과 칸이 늘 둘째 줄 — 계산 중 위아래 움직임 없앰.
- (2026-11-24) 상단 칸 이름 `광량` → `휘도`. 2D 지도 옆 단위 선택 `cd/m²`(기본) ↔ `100%`: 2D 눈금·마우스 값·상단 칸이 함께 바뀜. cd/m² 눈금 = 평균 휘도 ÷ (판정 칸 면적 평균 / 가장 밝은 칸) — 지도와 휘도가 같은 ±10° 집계라 판정 각도 10° 면 그대로, 가정 휘도면 `≈cd/m²`. 100% 쪽 상단 칸 = `평균 광량 NN%`(평균 / 가장 밝은 칸 — 2D 와 같은 기준). 이 브라우저에 기억(uds.m3.lumUnit).
- (2026-11-24) 상단 칸 툴팁 = 이름·값·목표 + 뜻 한 줄(짧게): 길이 `길이 방향 밝기 최저 ÷ 최고` · 폭 `약 N mm 구간마다 폭 방향 밝기 최저 ÷ 최고 — 가장 낮은 구간 값`(N = winS) · 효율 `LED 빛 중 정면으로 나온 몫 — 낮으면 흡수·새는 빛 많음` · 가정 휘도 설명도 한 줄로.
- (2026-11-24) 부품 표시 이름: 기본 이름 `부품 N` 은 재질로(Milky · 투명 PC · 반투과 백색 · 불투명 백색/금속/흑색 · PCB), 같은 재질이 둘 이상이면 1·2 번호. 사용자가 바꾼 이름·저장된 이름은 그대로(표시 전용, materials.js partNames).
- (2026-11-24) 계산 중 판정 글 = `미달 예상 −x%p`·`합격 예상`, 종합 배지 `✕ 목표 미달 예상`·`✓ 목표 통과 예상` — 판정 규칙·숫자는 그대로, 계산이 끝나면 `예상` 없음.
- (2026-11-24) 예제 여는 동안 시작 화면 선택 단추 숨김, `예제 '…' 여는 중…` 만 표시(3D 화면이 뜨면 풀림, 실패 시 오류 글).
- (2026-11-24) 상단 길이·폭 칸 평상시(판정 전·Quick) = 차분한 회청색 칸(#16294a) · 옅은 글씨, 글자 테두리 없음. 판정이 나오면 기존처럼 바탕 파랑/빨강/주황 + 흰 글씨·진한 파랑 테두리.
