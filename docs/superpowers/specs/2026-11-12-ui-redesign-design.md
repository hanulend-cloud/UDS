# UDS 화면 다시 그리기 — 설계 (2026-11-12, 사용자 승인: "이대로 실제 프로그램에 적용")

시안: `docs/ui-mockup/uds-ui-mockup.html` (Edge 로 열기). 이 문서는 시안을 실제 프로그램에 옮기는 범위·순서·지킬 것을 정한다.

## 지킬 것(모든 단계)
- 기능은 하나도 빼지 않는다. 메뉴 항목, 단축키, 우클릭 메뉴, 큰 창(확대·영역 선택·오른쪽 끌기 이동), 기구 최적화(위치·형상·Milky, Milky 5 상한), 속성 칸, 저장 형식은 그대로.
- 판정 숫자·계산·엔진은 손대지 않는다(표시만 바뀜). 균일도는 fmtJudge, '노이즈' 용어 유지.
- 기존 시험(`npm test`, `npm run test:m3`)이 계속 통과. 단계마다 Edge 기준(127.0.0.1:5180) 브라우저 확인 후 커밋.
- 숫자 칸 commit-input 규칙(Enter·Tab·버튼 누름 확정) 유지.

## 무엇이 바뀌나
1. 색·글꼴 하나로 — `#mech3d-wrap` 의 `--m3-*` 변수를 화면 전체(상단 바 포함) 토큰으로 넓힘. 강조색 파랑 하나, 상태색 통과 초록·미달 빨강·주의 주황. 큰 창(청록)·모니터(보라) 고유색 제거. 글꼴 Noto Sans KR(없으면 시스템), 숫자는 자리 맞춤. 버튼 높이 3종(34·38·46px), 본문 15px.
2. 밝은/어두운 전환 — 화면 전체가 따라감. 상단 바 ☀/☾ 단추 + 기존 '보기 › 3D 배경 어둡게' 메뉴는 같은 동작. 보는 사람별로 기억(지금 3D 배경 설정 저장 위치 그대로).
3. 상단 바 한 줄 — 로고·메뉴 6개 · 프로젝트 이름·저장 상태·[파일로 저장] · GPU 배지 · ☀/☾.
4. 왼쪽 기둥 — 위: 작업 단계 ①~⑤ 세로(지금 위쪽 가로 단계 막대를 옮김, 상태·요약·누르면 하는 일 그대로). 아래: '구성' 트리 — 관측면 · 부품 · 광원을 같은 단계 그룹(▾/▸, 아이콘, 개수). 관측면·부품 펼침, 광원 접힘이 기본. 기존 트리 기능(보이기, 소재 배지, 우클릭 그룹, 선택) 유지.
5. 가운데 3D — 오른쪽 세로 보기 단추 묶음을 3D 위쪽 가운데 떠 있는 얇은 막대로: XY·XZ·YZ·등각 + 반대 · 맞춤 · 투시 · 선 · 광경로 · 관측면 · 밝게(아이콘, 마우스 올리면 이름). 광량 범례 왼쪽 아래.
6. 오른쪽 — [결과] [속성] 탭. 결과: 판정 배지, 길이·폭 균일도 큰 숫자 + 목표선 막대, 새는 빛·오차·광선 칩, 2D 미니 지도(⤢ 크게, 선택 영역 한 줄), 1D 두 개, 접힌 '계산 오차·균일도 추이·광경로'. 속성: 지금 속성 패널을 그대로 옮김(부품 고르면 자동으로 이 탭). 기구 최적화 패널 자리는 지금처럼 유지.
7. 아래 상태줄 — 실행·일시정지·중지, 진행률, 광선 수, 오차, 상태 글, 화질 선택(지금 시뮬 카드 머리의 것을 옮김).
8. 떠 있는 창(큰 창·기구 최적화·모니터) — 같은 머리 모양(패널색 머리 + 제목 + ✕), 고유색 없음.

## 단계(각 단계 = 커밋 하나, 끝날 때마다 Edge 확인)
1. 토큰·전체 테마 전환(1·2·8의 색) — 모양은 그대로, 색만 통일.
2. 상단 바(3).
3. 왼쪽 기둥: 세로 단계 + 같은 단계 트리(4).
4. 3D 위 보기 막대(5).
5. 오른쪽 결과/속성 탭과 결과 카드(6).
6. 아래 상태줄(7).
7. 마무리: 좁은 화면(1024px 이하) 쌓임, 대비 점검, 남은 고유색 정리.

## 시험
- 단계마다: `npm test`, `npm run test:m3` 통과.
- 새 순수 함수(테마 저장·읽기, 단계 요약 글 등)는 TDD.
- 브라우저: 예제 불러오기 → 계산 → 큰 창·영역 선택 → 최적화 창 열기 → 테마 전환을 단계마다 한 번씩.
