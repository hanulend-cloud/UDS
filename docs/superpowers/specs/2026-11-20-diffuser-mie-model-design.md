# 확산판 모델 Mie 전환 — 설계 문서 (2026-11-20, rev.2 — 평가 반영)

## 1. 목표·원칙
- **겉보기 = Milky, 계산 = Mie.** 기구설계자 화면의 입력·출력은 Milky(0~10) 하나. 내부 계산은 모두 Mie 입자 산란.
- 목표: 다른 조건(LED·반사·형상)이 맞을 때 확산판 예측이 실측과 90% 수준으로 맞도록 — 확산판이 가장 어려운 항목.
- HG 는 **사용자 모델이 아님** — 내부 가속용(다중산란 구간, 결과 동일)으로만 남김. 화면 어디에도 HG 선택지 없음.
- 기존 .uds 도 새 기준(Mie)으로 계산. 이전 버전·기존 파일 설명은 넣지 않음(사용자 결정).
- 판정 숫자가 바뀜 — 사용자 승인됨(2026-11-20). Milky 범위 0~10, 최적화 상한 Milky 5 는 그대로.

## 2. 현재 상태(근거)
- 추상 Milky: `l2/material.js` HG g=0.9, μs′ 는 `l2/milky.js`(2mm 기준판 차폐율, HG 응답표).
- 실측 DB 소재: `l2/material-fit.js` HG 먼저, 실패 + 비드 정보 있으면 Mie 재피팅 · 소재별 응답표(`mie-material.js`).
- 3D: `mc3d.js`·`gpu-trace.js` 가 위상표(Mie) 샘플링 지원 — DB Mie 소재만 사용 중.
- 소재 DB 관리 창(관리자 모드, `app.js openMaterialDb`) 확산 탭 = 법선 입사 BSDF·T·R·Haze 입력 → 피팅.

## 3. 1단계 — 모든 확산 계산을 Mie 로
### 3.1 기본 비드(수지별 프리셋)
| 모재 | 비드 | n_host / n_p | 지름 | 크기 편차 |
|---|---|---|---|---|
| PC | 가교 PMMA | 1.586 / 1.49 | 3 µm | 로그정규 σ ≈ 0.25 |
| PMMA | 실리콘 | 1.49 / 1.43 | 2 µm | 로그정규 σ ≈ 0.25 |
- 그 밖의 수지는 굴절률이 가까운 프리셋을 씀(굴절률은 부품 수지 값).
- `mie.js` 에 크기 분포 평균(지름 15점 가중 — Qsca·위상함수를 단면적 가중 평균) 추가.

### 3.2 Milky 눈금
- 뜻 유지: Milky = 10·(1 − T(2mm)/T(0)), 기준판 = **그 프리셋의 Mie 응답표**(확산 입사).
- Milky → μs′ → μs = μs′/(1−g_Mie) → 수밀도 → 체적분율 φ → wt%. 대응표는 프리셋마다 1개.
- **흡수는 비드 농도에 묶음**: μa = μa_resin + κ_φ·φ. κ_φ 는 Milky 5 에서 현재(HG) 흡수와 같아지도록 정함.
  (평가 ②: 기본 비드 g ≈ 0.99 라 같은 μs′ 에서 μs 가 HG 의 약 10배 — 기존 식 κ·μs 를 쓰면 흡수가 10배가 되어 광효율이 크게 틀림.)
- 기본 비드 g(550nm, 단일 지름 계산값): PMMA 3µm in PC 0.991, 실리콘 2µm in PMMA 0.988.

### 3.3 응답표
- 프리셋 Mie 응답표를 도구 스크립트(`tools/build-mie-preset.mjs`)로 미리 계산해 저장소에 넣음 — 실행 중 비용 0.
- τ′ > τ′_M 구간은 같은 g 의 HG 주 응답표로 연결(기존 `compositeTable`, V13 연속성 |ΔT|,|ΔR| ≤ 0.01).
- 미리보기·L2·Milky 최적화·차폐 계산은 이 합성표를 씀.

### 3.4 3D 계산
- 모든 Milky 부품 = 프리셋(또는 DB) Mie 위상함수 샘플링(CPU·GPU).
- **델타 절단 필수**(평가 ①): g ≈ 0.99 라 그대로 쓰면 확산판 안 산란 횟수가 현재의 약 10배.
  전방 피크(θ < θ_c, 비율 f)를 빼고 μs* = μs·(1−f), 잘린 위상함수(정규화)로 샘플링 — μs′ 보존.
  θ_c 는 결과 동등성(절단 전후 T·R ≤ 0.01, HPA ≤ 1°, 스폿 곡선 반폭 ≤ 2%)을 만족하는 가장 큰 값.
- 목표 3D 계산 시간 ≤ 현재의 1.3배(같은 장면·광선 수). 넘으면 θ_c·광선 수를 보고하고 결정을 받음.

### 3.5 검증
- Milky ↔ wt% 단조, Milky 0/10 끝값.
- **기본 비드 대표성**(평가 ③): DB 실측 3종(DQ5122·5142·5162)을 같은 Milky 의 기본 비드로 계산한 T·R·HPA 오차를 표로 기록.
  합격 기준(§3.6)을 넘는 소재가 있으면 Milky 구간별 비드 지름 프리셋이 필요한지 판단 자료로 보고(자동 변경 안 함).
- 같은 Milky 에서 광효율이 현재(HG)와 비슷한지(흡수 보정 확인) 기록.
- 3D MC vs 응답표(같은 평판) T·R 차 ≤ 0.01. 델타 절단 전후 T·R·HPA 차 ≤ 0.01 / 1°.
- 전체 테스트 스위트 통과(판정 기대값은 새 기준으로 갱신 — 바뀐 값 목록을 보고).

### 3.6 소재 합격 기준(예측 정확도 — 평가 ④)
- 측정 두께에서: 전투과 T ±2%p, 전반사 R ±2%p, HPA ±2°, 각분포 모양 오차(V6) 통과.
- 스폿 사진: 반경 밝기 곡선 반폭 ±5%, 중심 대비 10% 밝기 반경 ±5%.
- 이 기준을 만족하면 신뢰 표시 `실측보정`, 넘으면 `실측보정(오차 큼)`.

## 4. 2단계 — 상단 「개발자」 메뉴 · 확산 모델 창
- 상단 메뉴에 **「개발자」** 신설. 「설정」에 있던 `관리자 모드`, `소재 DB 관리…` 를 옮김.
- **확산 모델 (Mie)…** 창(새로):
  - 수지별 기본 비드 보기, Milky별 wt%·μs′·μs·g 대응표, 위상함수·예상 투과 각분포 그래프.
  - **신뢰 표시** 목록: 프로젝트 사용 소재·DB 소재별 `가정`(기본 비드) / `실측보정` / `실측보정(오차 큼)`(§3.6) / `측정 범위 밖`(사용 두께가 측정 두께 범위의 0.5~2배 밖, 또는 입사각이 측정 범위 밖 — 첫 기준값, 실측이 쌓이면 조정).
  - **Mie 값 수정**: 관리자 모드에서만(비드 종류·지름·편차·모재 굴절률). 바꾸면 응답표를 백그라운드 Worker 로 새로 만들어 캐시(처음 1회 30~100초). 수정값 저장 위치(평가 ⑤):
    - 수지별 기본 비드 수정 → 그 프로젝트(.uds)에만 저장(다른 프로젝트·DB 영향 없음).
    - DB 소재의 Mie 값 → 소재 DB 관리 창에서만 수정(DB 에 저장).
- Milky 입력란·부품 속성은 바뀌지 않음(작은 표시 없음).

## 5. 3단계 — 실측 BSDF 로 Milky 소재 추가(소재 DB 관리 › 확산 탭)
- 모델 = Mie 만(HG 피팅 결과는 사용자 경로에서 제거). 비드 정보가 없으면 기본 비드 종류로 지름·농도·흡수를 맞춤.
- 입력 확장: 시료별 두께 여러 개 + 입사각(0° 외 비스듬한 입사) BTDF/BRDF.
- 보간이 아니라 **역산 → 물리 계산**: 맞춘 Mie 값으로 다른 두께·각도를 MC 로 계산.
- 측정 범위(두께·입사각)를 DB 항목에 저장 → 2단계 신뢰 표시에 씀.
- 기존 HG DB 항목은 Mie 로 다시 피팅.
- **Mie 가 실측과 안 맞을 때**(평가 ⑥): 가장 잘 맞는 Mie 값을 쓰고 `실측보정(오차 큼)` + 오차 항목 표시. HG 로 돌아가지 않음.

## 6. 4단계 — LED 1개 스폿 사진 측정(같은 탭)
### 6.1 측정 기준(화면 안내에 표시)
- 시료: 평판, 제품 두께, 크기 ≥ 6·(간격+두께).
- LED 1개, 정전류 5~20 mA. **LED DB 에 배광이 있는 품번만** 흡수까지 맞춤(평가 ⑦: 배광 오차가 소재 값에 섞이지 않게). 배광이 없으면 곡선 모양(퍼짐)만 맞추고 흡수는 기본값.
- 간격(LED 윗면~판 아랫면) 2개 이상, 스페이서 ±0.1 mm.
- 바닥 무광 검정, 암실.
- 카메라 수직, 300~500 mm, 판 면에 자. 수동 노출·ISO 최저·WB 고정, RAW 권장, HDR·보정 끔, 최대 밝기 ≤ 80%.
- 노출 ±2스톱 3장 + LED 끈 사진 1장(휘도 카메라는 1장). 선택: 중심 휘도(cd/m²).
### 6.2 처리
- 사진 → 바탕 빼기 → 노출 합성(선형) → 자로 mm 눈금 → 중심 찾기 → 반경 밝기 곡선(정규화).
- UDS 가 같은 배치(LED 배광·간격·두께·검정 바닥)를 MC 로 계산해 곡선을 맞춤 → Mie 지름·농도(휘도 있으면 흡수까지).
- 결과는 BSDF 피팅과 같은 DB 항목으로 저장(측정 종류 = 스폿 사진), BSDF 와 함께 있으면 둘 다 목적함수에 넣음.
